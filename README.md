# frontend-machine-coding

A collection of frontend machine coding implementations built using React, TypeScript, and modern frontend engineering practices. Focused on scalable UI architecture, performance optimization, reusable components, clean code structure, and production-level frontend development patterns.

## Setup

```bash
npm install
npm run dev
```

Opens at http://localhost:3000

- Client pagination: open `/` after `npm run dev`.
- Server pagination: open `/server-pagination`.
- Custom form: open `/form`.
- Acronym Finder: open `/acronym-finder`.
- Accordion Finder: open `/accordion`.
- Nested Comments: open `/comments`.
- Infinite Scroll: open `/infinite-scroll`.
- Image Slider: open `/image-slider`.
- Search Autocomplete: open `/search-autocomplete`.
- Accessibility: open `/accessibility`.

## Scripts

| Command             | Purpose                      |
| ------------------- | ---------------------------- |
| `npm run dev`       | Dev server                   |
| `npm run build`     | Typecheck + production build |
| `npm run typecheck` | TypeScript only              |
| `npm run lint`      | ESLint                       |
| `npm run format`    | Prettier                     |

## Structure

- `src/components/` — reusable UI
- `src/pages/` — route screens
- `src/routes/` — React Router setup
